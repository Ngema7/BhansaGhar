## 🏔️ About

**BHANSA GHAR** is a premium, traditional **Nepali restaurant website** that brings the warmth of Nepali hospitality to the screen. Heritage-inspired visuals, Newari-style woodwork motifs, a rich maroon-and-gold palette, and a fully bilingual experience (English and नेपाली) make every visit feel like walking into the restaurant itself.

> *"More Than Food, It's Our Heritage."*

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🏠 | **Home** | Cinematic hero, signature dishes, and quick actions |
| 📜 | **Our Story** | Heritage storytelling with values: Authentic Recipes, Fresh Ingredients, Warm Hospitality |
| 🍽️ | **Menu** | Category filters (Nepali Thali, Momos, Sekuwa, Traditional, Drinks) with prices in Rs. |
| 🖼️ | **Gallery** | Photo grid showcasing the ambience and dishes |
| 📅 | **Reservation** | One-tap booking via **WhatsApp** or direct **call** |
| 📍 | **Contact** | Address, opening hours, social links, and embedded map |
| 🌐 | **EN / NE Toggle** | Instantly switch between English and Nepali |
| 🎞️ | **Smooth Animations** | Page and scroll transitions with Framer Motion |
| 📱 | **Fully Responsive** | Mobile-first layouts for every screen size |

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18 or higher
- **npm** / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/ngema-theeng/<repo-name>.git

# Enter the project
cd <repo-name>

# Install dependencies
npm install

# Start development server
npm run dev
```

Open **http://localhost:5173** and enjoy the experience. 🍛

### Scripts

| Command | Action |
|---|---|
| `npm run dev` | Start dev server with hot reload |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build |

## ☁️ Deployment

Deployed on **Vercel**.

1. Push the repo to GitHub
2. Import it on [Vercel](https://vercel.com/new)
3. Preset: **Vite** · Build: `npm run build` · Output: `dist`
4. Click **Deploy** 🚀
